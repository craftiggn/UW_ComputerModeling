### **1. Architecture & Core Simulation (Numba)**
Use `@njit` from `numba`. Pre-allocate all states using 1D numpy arrays of size `N_MAX` (e.g., `pos_x`, `pos_y`, `is_living`, `parent_ids`). 

**Spatial Hashing:**

**Physics Engine (`get_admissible_angle`):**
Write a `@njit` helper function that evaluates a 5x5 grid neighborhood around a candidate cell. 
* A cell (radius $r=1$) can only be placed at exactly distance 2.0 from its parent.
* Iterate through neighboring grid cells to find existing simulation cells.
* If a cell is closer than distance 4.0, calculate the blocked angular interval using `np.arccos(dist / 4.0)`.
* Handle circular wrap-around for intervals (0 to $2\pi$).
* Because native sorting isn't supported in Numba, use a manual bubble sort to order the blocked intervals by start angle.
* Merge overlapping intervals and find the total available gap.
* If gaps exist, sample a uniform random angle within the available gaps. If fully blocked, return `-100.0`.

**Simulation Loop (`run_eden_c_simulation`):**
* Initialize cell 0 at `(0,0)`. Set its `parent_id` to `-1`.
* Maintain a pool of living indices using a `living_indices` array and a `living_map` to achieve $O(1)$ random selection and deletion.
* In a loop up to `N_MAX=50000`, pick a random living cell. Call `get_admissible_angle`.
* If an angle is returned, create the new cell, add it to the grid, record its parent in `parent_ids`, and add it to the living pool.
* If `-100.0` is returned, mark the parent as dead and remove it from the living pool.
* **Tracking Statistics:** Every `track_interval=100` steps, compute the center of mass, and evaluate the *true boundary* (filter out "lazy-dead" cells by re-evaluating `get_admissible_angle`). Record the true living count ($L$), mean radius ($R$), and boundary thickness ($\sigma$).
* **Snapshot:** Exactly at 3,000 cells, capture copies of the `pos_x`, `pos_y`, `is_living`, and `parent_ids` arrays for later plotting.
